# 小蚕净化 (XiaoCanPurify)

LSPosed module that removes ads, popups, and redundant bottom navigation items from the Xiaocan app.

## What it does
- Blocks startup, feed, interstitial, and popup ads.
- Simplifies the bottom navigation to Home, Orders, and Me.
- Filters background ad requests and silent task loading.
- Uses LSPosed / libxposed API 102.
